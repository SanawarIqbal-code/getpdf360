PDF to PowerPoint questions

How do I convert a PDF to PowerPoint for free?

Choose Editable or Exact look, then select your PDF in the box above. Download the .pptx file. There is no sign-up and no cost.

Which slide type should I choose?

Choose Editable if you want to change the words. Choose Exact look if you want the slides to look exactly like the PDF, for example to present it.

Can I edit the text?

With Editable, yes: text comes through as text boxes you can change. Complex layouts may need tidying. With Exact look, each slide is a picture.

Does it work with scanned PDFs?

Exact look works with any PDF. For editable text from a scan, use OCR PDF first.

What happens to my file?

It is uploaded over HTTPS, converted on our server in London and deleted as soon as the PowerPoint file is sent back to you.
